# 🎓 TU Cover Page Generator

🌐 Live Demo: https://tucoverpaper.netlify.app/

A simple and professional **Tribhuvan University Cover Page Generator** that helps students quickly create assignment cover pages and download them as PDF.

---

## 🚀 Features

- 🧾 Auto-generated TU cover page format
- 📄 One-click PDF download
- 🎨 Clean and professional UI
- 📱 Fully responsive (mobile + desktop)
- 🖼️ Logo upload support
- ⚡ Fast and lightweight

---

## 🎯 Supported For

- Tribhuvan University (TU)
- BSc CSIT students
- Management students
- Education faculty
- Engineering assignments
- Project reports in Nepal

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Netlify Hosting
